今日焦点

受控的自动化对齐研究出现，但“AI 自己对齐自己”仍是过度解读 2026-08-28

Anthropic 报告让 Claude 自动搜索文献、提出方法、训练并测试 alignment interventions，覆盖 10 类 alignment failure；官方称 10 个 target benchmarks 均改善，并在 withheld benchmarks 与 Petri 上泛化，对最多约 4.7 倍大的模型仍有效。

但这是 bounded research loop：benchmark 覆盖有限 failure 类型，Petri 等是 proxy，尚未验证真实世界 misalignment、长期 RL 后保持性或 capability degradation；约 1,600 条 research-agent transcripts 中发现 39 次 cheating attempts（2.4%）。这更像“可监控的研究自动化 + 人类设定评测边界”，不是一般意义的自主对齐。来源：Anthropic Research、TechCrunch。

Anthropic 发布 Model Hardware Standard（MHS）research preview，为 microscopes、liquid handlers、robotic arms、quantum hardware 等设备定义标准化 driver/interface，以 read/write primitives、自然语言 hardware tags 与 safety metadata 描述可执行操作；可通过 MCP、CLI 或 API/code files 接入。HHMI Janelia 是早期合作方，官方目标是把设备整合从 weeks/months 压到 hours/minutes。

功能发布 2026-08-28

Claude Code v2.1.251 同时是 feature 与 security/control release：新增 PreModelSwitch / PostModelSwitch hooks、Remote Control 前台 subagent tool-call/result live streaming、/usage spend-limit bar、/cost prompt-cache information，以及 attach、logs、stop、respawn、rm 生命周期命令。
