今日焦点

8/18 OpenAI：Astra 可能触及 cyber-critical 门槛，frontier development 放慢

在 Hugging Face 事件背景下，OpenAI 表示内部模型 Astra 可能触及 Preparedness Framework 的 Critical cybersecurity capability 阈值，因此暂停面向部署模型的 reinforcement-learning training 两周，最大 planned frontier RL run 仍在暂停；部分 Astra workload 需迁入更强的 workload／network isolation 后才恢复。

新监控从每个 sampled token 的 activation classifier 开始，检查 tool actions、可用 reasoning 与完整 activity sequence；针对疑似 critical boundary violation，目标是在发现异常后 30 分钟内告警，无法排除误报就暂停活动，监控开销约为被监控 inference compute 的 20%。这不是普通安全声明，而是把训练速度、工具权限、网络边界与运行时监控绑成一个开发基础设施 gate。

来源：OpenAI 原文；TIME 原访谈；The Verge。建议：立即把 agent 的 network egress、tool scope、untrusted output 与高影响动作 gate 视为架构层控制，而非只依赖 sandbox。
