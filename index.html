Anthropic 把 frontier 模型的能力、成本与审计控制一起改版 9/1

Anthropic 同日发布 Claude Fable 5.1（一般可用）与 Claude Mythos 5.1（仅 trusted access）；两者使用相同模型权重，差别在 safeguards。Fable 5.1 的 cache read 从每百万 token 1 美元降至 0.25 美元，输入／输出标价仍为 10／50 美元；Anthropic 估计一般工作负载成本降约 25%，高度 agentic 工作最高约降 45%。官方表格显示 Terminal-Bench-Science 0.1 为 52.6%，Fable 5 为 24.7%，但这些仍是厂商评测。

Artificial Analysis Intelligence Index 给 Fable 5.1 最高 effort 评分 66，暂居其测量榜首；该评测说明约 4% output tokens 来自 Anthropic 的 default fallback，同时指出它因输出 token 量约为 Fable 5 的 1.7 倍，单任务成本反而高约 20%。这意味着“cache 更便宜”不等于“每个复杂任务都更便宜”，应以 Kevin 的真实 agent workload 做对照。配套的 Enterprise Frontier Safeguards（EFS）则把活动数据与自动滥用检测移到客户控制的 cloud account；相关 customer-owned storage、CMK 与 automated review 均为 opt-in，不改变模型行为、API 价格或 rate limit。EFS 预计秋季分阶段推出，合资格企业过渡期可申请 ZDR，但 GA 不等于所有入口／企业立即可用；客户仍承担 cloud storage、读写、egress 与监控成本。

OpenAI 宣布 Astra 首次达到其 “Critical” cybersecurity capability threshold 9/1

OpenAI 表示，Astra 在具备适当工具与权限时，能够在没有逐步人工引导的情况下发现此前未知的安全缺陷，并在多类 hardened systems 上设计 exploit；这是该公司首次把模型标为 Preparedness Framework 的 Critical cyber capability。官方还称内部评测中发现并使用两个 zero-day，正向维护者披露，但公开结果仍主要是 OpenAI 自报。

部署方式是先限制先进 cyber 能力给 Daybreak Blue 测试者，再逐步扩大防御性使用；高风险账号会采用更保守的行为边界，并配合实时监控与 containment。OpenAI 报告 cyber jailbreak refusal rate 为 91.5%，GPT-5.6 Sol 为 59%；TechCrunch 同时指出，外部尚无独立确认，且具体 safeguard 细节要等 system card。对 Kevin 的实际含义不是“立即使用强 cyber 能力”，而是把分级访问、网络出口、凭证隔离、审计与可快速终止作为默认架构。
